# Règles de sécurité initiales

- Repository privé, accès minimum nécessaire et authentification forte recommandée.
- Ne jamais versionner les secrets, tokens, clés, CV ou transcriptions réelles.
- Secrets d'environnement via coffre/secret manager, jamais dans Git.
- PR et revue obligatoires avant intégration à `main` (configuration manuelle des rulesets).
- Données de démonstration synthétiques; consentement et rétention à cadrer avant toute collecte.
- Révoquer immédiatement toute clé divulguée; nettoyer l'historique si nécessaire.
- Journaliser les décisions de conformité Maroc/international avant déploiement public.
