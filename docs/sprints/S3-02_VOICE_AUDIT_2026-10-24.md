# S3-02 — Stabilisation vocale : premier audit

## Périmètre et preuve
- Audit du composant Next.js `web/src/app/interview/page.tsx`, de la passerelle `web/src/app/api/interview/[action]/route.ts` et du moteur Python `dev/local-preview/server.py`.
- Source Python : endpoints `/api/ai/tts`, `/api/ai/transcribe`, `/api/ai/session/start`, `/api/ai/session/answer`.
- La passerelle appelait incorrectement `/api/ai/session/tts` et `/api/ai/session/transcribe` pour les POST.

## Modification
- `POST /api/interview/tts` et `POST /api/interview/transcribe` routés désormais vers les vrais endpoints Python. Les actions `start` et `answer` conservent `/api/ai/session/{action}`.
- Aucun changement de l'UI ni des données de candidat.

## Vérifications
- ESLint, TypeScript et `git diff --check` : PASS.
- `test_ai_interview_lab.py` : 12 PASS ; `test_interview_session_orchestrator.mjs` : 5 PASS.
- Test authentifié `web/tests/test_s3_02_voice_api.py` ajouté pour valider la réponse d'erreur 400 du moteur sur payloads invalides, sans transmission audio.
- **BLOQUÉ** : serveur Python actuellement actif sur le port 8765 répond `404 not_found` même directement à `/api/ai/transcribe`, pourtant présent dans le fichier source actuel. Le test E2E échoue donc toujours en `404`; la correction de routage n'est PAS encore validée bout en bout contre ce processus. Vérifier l'instance Python active et relancer le moteur à partir de la version courante dans une fenêtre maîtrisée, puis relancer le test.

## Autres risques à instruire dans S3-02
- API Next.js liée à `127.0.0.1:8765` : ne fonctionne pas telle quelle sur un déploiement Vercel distant.
- TTS Python repose sur `say` et `ffmpeg` macOS : solution de labo, pas infrastructure cloud.
- Essais manuels navigateur encore requis : permission micro, perte du micro, pause/reprise, auto-listen, arrêt, délai et échec de la transcription.
- Vérifier qu'une session IA locale est lancée avec une configuration de fournisseur correcte avant de tester les conversations réelles ; ne jamais exposer les clés API.
