# Conventions de contribution

## Branches
`main` = branche stable; `feat/<ticket>-<sujet>`, `fix/<ticket>-<sujet>`, `chore/<ticket>-<sujet>`, `docs/<ticket>-<sujet>`.

## Commits
Conventional Commits : `feat:`, `fix:`, `chore:`, `docs:`, `test:`, `ci:`. Messages concis; une modification logique par commit.

## Pull Requests
- Lier la tâche ClickUp, expliquer la portée et le plan de test.
- Au moins une revue d'un autre membre avant fusion (à configurer dans GitHub Settings).
- Pas de push direct sur `main` après activation des protections.
- Préférer squash merge; traiter les commentaires avant fusion.
- Pas de secrets, identifiants, CV, transcriptions ou données personnelles dans les commits/logs.

## Definition of Done
Critères d'acceptation satisfaits; vérifications CI vertes; revue approuvée; documentation actualisée; risque sécurité et données évalué.

## Responsabilités proposées
Achraf : priorisation et validation produit. Othmane : coordination technique/DevOps. Mehdi : contribution technique et revue croisée. À confirmer en équipe.
